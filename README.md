# Balchik Property Hunter — уеб версия

Това е версия без локална инсталация. Сайтът се отваря през браузър чрез GitHub Pages, а търсенето работи на GitHub Actions на всеки 6 часа.

## Какво следи

- Регистъра на публичните продажби на Камарата на ЧСИ: `sales.bcpea.org`
- Обявленията за ЧСИ, синдици и ликвидатори на Община Балчик
- Търговете и конкурсите на Община Балчик

Текущите филтри са в `config.json`: максимална цена 200 000 лв. и населени места около Балчик.

## Настройване само през браузъра

### 1. Създай GitHub repository

1. Влез в github.com и избери **New repository**.
2. Име: например `balchik-property-hunter`.
3. Най-лесно е repository-то да е **Public**. Самите обяви са публични; паролата и имейлът няма да се записват в кода.
4. След създаването избери **Add file → Upload files** и качи всички файлове и папки от този пакет, включително `.github`.
5. Commit-ни файловете.

### 2. Добави защитените имейл настройки

В repository-то отвори **Settings → Secrets and variables → Actions → New repository secret** и добави:

- `ALERT_EMAIL_TO` = имейлът, на който искаш известия
- `SMTP_USER` = Gmail адресът, от който ще се изпращат
- `SMTP_APP_PASSWORD` = Google App Password (не нормалната Gmail парола)

За Google App Password е нужна включена 2-Step Verification в Google акаунта.

### 3. Пусни първото търсене

Отвори **Actions → Update Balchik property listings → Run workflow**.

При първото изпълнение текущите обяви се записват като начална база и по подразбиране не се праща стар backlog. Следващите нови попадения ще се изпращат по имейл.

### 4. Включи сайта

Отвори **Settings → Pages** и под **Build and deployment** избери:

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/(root)**

След запазване GitHub ще покаже адрес от вида:

`https://USERNAME.github.io/balchik-property-hunter/`

От този момент сайтът се отваря от браузър и не изисква инсталиране на нищо на компютъра.

## Смяна на бюджета и районите

Отвори `config.json` директно в GitHub и натисни иконата с молив. Можеш да променяш:

- `max_price_bgn`
- `min_area_sqm`
- `locations`
- `property_keywords`

После избери **Commit changes**. Следващото автоматично търсене ще използва новите настройки.

## Автоматично обновяване

`.github/workflows/update.yml` е настроен да се стартира приблизително на всеки 6 часа. GitHub може понякога да забави планираните задачи. Можеш по всяко време да стартираш ръчно от **Actions → Run workflow**.

## Сигурност

Не записвай Gmail App Password в `config.json`, `scraper.py` или друг файл. Дръж го само като GitHub Actions Secret.

## Важно

Ниска начална цена при публична продан не означава автоматично изгодна или безрискова покупка. Проверявай тежести, собственост, идеални части, владение, кадастър и документите по изпълнителното дело преди участие.
